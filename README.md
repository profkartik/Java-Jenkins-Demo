# Java Jenkins CI/CD Demo

A sample Java project_5 demonstrating automated builds and continuous integration using **Jenkins** and **GitHub Webhooks**.

---

## 🚀 Features

* **Automated CI/CD:** Triggers a Jenkins build automatically on every `git push`.
* **Pipeline as Code:** Uses a `Jenkinsfile` for declarative build steps.
* **Webhook Integration:** Connects local Jenkins via `ngrok` tunneling.
